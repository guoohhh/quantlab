# QuantLab vNext · Professional Workbench 03

本目录是独立的产品设计与高保真原型，不修改 `dashboard/`、后端金融规则或生产数据。

本版在 **Evidence Trace / Quiet Signal（证据有迹 / 安静信号）** 视觉语言上，进一步建立面向经验投资者的专业工作台：今日、市场与发现、研究台、组合、复盘五个稳定工作域；纯新手说明由帮助中心承接。

## 交付内容

- `FRONTEND_HANDOFF.md`：供主干 AI 接手的范围、authority、验证结果与生产实施顺序。
- `PRODUCT_DESIGN_VNEXT.md`：真实体验审计、信息架构、核心路径、页面方案、状态体系、帮助中心与视觉系统。
- `prototype/index.html`：可交互高保真原型。
- `prototype/styles.css`：品牌、字体、可视化、Quiet Signal 动效、响应式与状态样式。
- `prototype/app.js`：导航、搜索、Chat、动态中心、订单实时重算与确认、帮助内容、状态演示和环境等高场。
- `audit/prototype_qa.mjs`：1440 / 900 / 390 三档浏览器截图和溢出检查。
- `audit/prototype_interaction_qa.mjs`：订单方向与硬阻断、搜索、自选、reduced-motion 等交互检查。
- `audit/typography_qa.mjs`：以 DPR 2 生成桌面首屏，并核对实际字体、字重、小字号和浏览器错误。

## 查看原型

直接打开 `prototype/index.html` 即可。为获得与本轮验证一致的效果，也可以在该目录运行：

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8123`。

建议按以下顺序体验：

1. “今日”查看市场、组合、研究和证据四类仪表摘要；
2. “研究台”查看活跃论文、七证据域与研究流水线；
3. 从“市场与发现”或研究台打开贵州茅台对象工作区；
4. 查看关键事实、支持与反证、失效条件和来源审计；
5. 打开右侧 Chat；
6. 点击“创建模拟订单草稿”，走完订单、检查、确认三步；
7. 在“组合”查看持仓、盈亏、约束、订单和账户隔离；
8. 在“复盘”查看原判断、用户选择和结果时间线；
9. 使用顶部“状态演示”切换空数据、加载、降级、错误和后台任务；
10. 查看“帮助中心”和“专业空间”。

建议特别观察：

- 首页的 Decision Atlas；
- 发现页的 Market Topology；
- 研究页的 Evidence Constellation；
- 交易前检查中的 Trade Folio；
- 用户确认阶段的 Evidence Seal；
- 专业空间中正式七影子、旧系统影子档案和 Historical Demo 的隔离。

## 原型边界

- 页面中的金额、行情、持仓和研究内容都是固定在 `2026-07-20 08:20` 的演示快照，顶部有持续标识。
- 原型不会调用真实数据源、LLM、SQLite 或券商。
- 它验证的是产品模型、内容层级、交互和视觉方向，不替代金融规则与审计实现。
- 当前生产状态和演示状态在设计文档中分开描述，不能把原型数字视为系统当前证据。
- 未接入完整报告的标的会 fail closed，不会复用贵州茅台的证据与订单上下文。
- 用户模拟、正式七影子、旧系统影子档案、外部记录和 Historical Demo 不混算。
