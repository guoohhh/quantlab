# 五个一级决策工作区用户流程

普通模式使用 session-state 驱动的单页导航。每次 rerun 只执行当前工作区；页面切换保留
`symbol`、`research_run_id`、`account_id` 和 `order_id` 原子上下文。高级/审计模式继续保留
完整工程页签。浏览首页、任务列表和通知列表默认只读；任务对账与通知 outbox 处理交给
Scheduler/Worker 或用户明确点击的刷新动作。

## 五个一级决策工作区

### 今日

展示最重要的决策任务、投资论文状态、账户盈亏、持仓、待处理订单、未读通知和数据状态。
没有动作也是合法结果；页面不会为了活跃度强行推荐。

### 市场与发现

展示市场状态、行业、搜索、候选、资金活跃度和数据新鲜度。资金数据明确区分已确认数据、
估算代理和不可用；资金不能单独生成买入结论。

### 研究台

展示建议动作、建议仓位、支持/反对证据、失效条件和证据块来源、时间、质量。Chat 绑定
当前标的与 `run_id`；复杂请求进入后台 Job。切换标的或请求日期会使不匹配的研究身份失效。

### 组合与交易

```text
选择用户模拟账户和操作
→ 后端使用服务器权威行情运行交易前检查
→ 页面展示支持、反对、失效条件、费用和组合影响
→ 用户明确确认
→ pending / 部分成交 / 成交 / 拒绝 / 过期
→ 订单时间线、成交费用、持仓、盈亏和净值
```

已成交订单不能撤销；撤销未完成订单会释放冻结现金或数量；账户、标的、方向、数量、行情或
研究身份变化后，旧检查失效。AI 不能自动确认订单，系统不连接券商。

### 决策复盘

只读聚合当前用户模拟账本、研究身份、订单、成交、费用、用户复盘和投资论文生命周期。
正式影子、Historical Demo、外部记录和旧系统档案不进入该时间线。

## 工具入口

工具入口不与五个决策工作区并列。侧栏的“我的与工具”提供全局 AI 助手、我的账户、通知与
任务、设置和帮助中心；其中账户、通知、任务、独立 Chat、Runtime 与证据状态汇入专业空间。

### 专业空间

包含真实只读组合、建议采纳、通知、任务、Chat、数据状态、持续运行状态和正式证据隔离。
真实组合外部成交只能由用户手工登记；采纳效果不进入训练或正式前瞻成绩。

### 帮助中心

包含快速开始、功能路径、AI 报告阅读方法、模拟交易规则、账户隔离、常见问题、后台任务、
降级与错误状态以及能力边界。帮助内容不依赖 Runtime，可在数据不可用时继续阅读。

全局 AI 助手按当前页面、账户、标的、研究和订单隔离上下文；交易或预警动作只能形成待确认
草稿，不能自动执行。

## 二级路由

- `研究详情` 从研究台进入，固定标的、请求日、有效数据日、`run_id`、证据来源和质量；
- `专家圆桌` 从研究台进入，围绕同一份冻结研究展示分歧、引用和未解决问题；
- `设置` 从专业空间或工具入口进入，管理本机模型 Provider、通知与偏好，不改变研究或交易权限。

## 工程边界

- Streamlit 页面只提交用户意图，不复制价格、订单、仓位、费用与权限规则；
- 研究报告必须有完整的标的、请求日、有效数据日和 `run_id`；
- 缺失、过期、降级和错误保持可见并 fail closed；
- 用户模拟、正式影子、历史演示、外部只读记录和旧档案严格隔离；
- 产品使用事件只用于使用分析，不能进入训练或正式 forward scorecard。
