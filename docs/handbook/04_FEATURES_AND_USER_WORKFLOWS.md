# 功能与用户使用流程

本文描述当前稳定的用户工作区和行为边界。具体按钮文案可能调整，服务器侧行情、风控、确认和
证据隔离规则不能由前端绕过。

## 五个一级决策工作区

### 1. 今日

首页回答三个问题：今天发生了什么、需要处理什么、账户现在怎样。它聚合总资产、现金、持仓、
今日/累计盈亏、论文红线、待确认订单、通知、后台任务和数据降级。没有建议也是合法结果。

### 2. 市场与发现

用户可以搜索 A 股/ETF、查看候选、自选、市场状态、行业与资金线索。资金流会标明真实字段、
估算代理或不可用状态，不能单独生成买单。候选只是“值得研究”，不是订单。

### 3. 研究台

研究列表支持分页、搜索和筛选。打开报告后进入二级研究详情路由；切换标的或日期时，不匹配的
冻结研究身份不得继续用于交易前检查。

长研究由后台 Job 执行，页面显示进度、取消、失败和重试。研究台不会因为等待 LLM 阻塞整个页面。

### 4. 组合与交易

用户模拟交易流程：

```text
选择账户与标的
  -> 输入方向和数量
  -> 服务器获取可操作行情
  -> 确定性交易前检查
  -> 展示费用、仓位、现金、风险和正反证据
  -> 用户明确确认
  -> pending / 部分成交 / 成交 / 拒绝 / 过期 / 撤单
  -> 持仓、已实现/未实现盈亏和净值曲线
```

AI 不推荐时用户仍可发起模拟操作，但不能跳过数据可用性和硬风险检查。用户模拟账户不会污染
系统策略的前瞻成绩。

### 5. 决策复盘

复盘页把研究、投资论文、用户决定、订单、成交、费用、后续行情和 Reflection 重新连接。它帮助
判断“当时依据是否合理”和“结果为何偏离”，但事件归因只能说明关联，不能自动证明因果。

## 工具入口

工具入口承接账户、通知、后台任务、帮助、设置与独立对话，不与五个决策工作区并列。

### 专业空间

专业空间承载低频管理能力：

- 外部真实组合的只读/手工登记与建议采纳；
- 通知中心、偏好、去重、冷却和投递状态；
- 独立 AI 对话与历史会话；
- 后台任务、Runtime、数据 readiness 和正式证据状态；
- DeepSeek、OpenAI 官方及 OpenAI-compatible 模型设置；
- 邮件收件地址与本机发件服务设置。

外部成交必须由用户登记，系统不会假装已连接券商。密钥不进入研究、聊天、订单或导出报告。

### 帮助中心

帮助中心包含快速开始、页面路径、报告阅读、模拟交易规则、账户隔离、后台任务、错误降级和能力边界。
它在数据源或模型不可用时仍应可读，并能跳转到对应工作区。

### 全局 AI 助手

助手可从工具区打开，并在当前路由继续使用。会话按页面、账户、标的、研究和订单精确隔离，回答可
显示引用证据。交易或预警操作只生成草稿，必须进入完整确认页重新核对数量、模式和最新行情。

## 二级路由

### 研究详情

研究详情从研究台进入，保留标的、请求日期、有效数据日、`run_id`、证据来源、支持/反对观点、
失效条件和数据质量。冻结身份不完整、过期或与当前操作不匹配时必须 fail closed。

### 专家圆桌

圆桌从研究台进入。参与角色围绕同一份冻结研究逐轮发言，用户可查看讨论过程、证据引用、分歧和
未解决问题。圆桌状态持久化，切换路由后可以恢复；它不会改变硬风控或直接创建订单。

### 设置与 Provider

用户可选择 DeepSeek、OpenAI Responses 或自定义兼容端点，填写各自模型、Base URL 和 API Key。
GPT 保留为可选能力，不强制作为活动路由。第三方兼容地址必须由用户明确填写，系统不能静默转发
官方 Key。

邮件通知区分“未配置、未启用、已排队、正在投递、重试、失败、SMTP 已接受”等状态。SMTP 接受
不等于邮件已经进入收件箱，测试邮件也必须经后台通知 Worker 投递。

## 性能与状态体验

- 页面切换只执行当前工作区，不同时渲染所有功能；
- 长任务进入后台并显示加载、进度、取消和恢复；
- 列表使用分页、搜索和筛选，避免无限向下堆叠；
- 空状态、降级、错误与重试应有明确用户文案；
- 桌面侧栏可折叠为图标栏，窄屏使用可点击的抽屉导航；
- 不应为了动画、图案或 Agent 视觉效果牺牲首屏和交互响应。

## 证据身份

页面必须区分实时/当前数据、历史研究、用户模拟、Historical Demo、影子账户和正式前瞻。只有满足
冻结协议、自然时间、点时数据与到期结算的样本才能进入对应正式成绩单。
