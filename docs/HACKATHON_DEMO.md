# QuantLab 黑客松现场手册

## 一键启动

在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-hackathon-demo.ps1
```

脚本会检查 `.venv`、Streamlit、产品入口和冻结数据集，优先使用 `8501`。如果端口被占用，
它会自动向后选择空闲端口，并在终端打印实际的本地 URL。演示结束后，在该终端按 `Ctrl+C`。

提前验场但不启动服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-hackathon-demo.ps1 -CheckOnly
```

指定首选端口，或不自动打开浏览器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-hackathon-demo.ps1 -Port 8510 -NoBrowser
```

## 启动边界

该脚本只启动绑定到 `127.0.0.1` 的 Streamlit 产品界面，并默认使用
`data/demo/hackathon-ui.db` 作为 UI 数据库。它会跳过项目 `.env`、强制使用 Mock LLM、关闭
OpenAI/DeepSeek 和可信数据自动刷新。

它不会启动 Scheduler、Worker、API、每日任务、正式实验或券商连接，也不会读取生产数据库作为
演示账本。冻结 Historical Demo 仍使用数据集指纹绑定的独立 SQLite；点击“重新开始”只会重置
这份隔离账本。

## 三分钟现场脚本

### 0:00 - 0:20：一句话建立差异

打开首页，指向“完整决策示例”，点击“打开示例”。

> 普通 AI 往往只给一个结论。QuantLab 保存支持证据、反对证据、失效条件和用户最后确认，
> 让一次投资判断可以被验证和复盘。

同时指出页面上的边界：这是冻结历史研究演示，不是实时行情、正式前瞻证据或收益承诺。

### 0:20 - 1:05：发现候选并冻结研究

点击“生成研究与交易前检查”。这一步会读取版本化候选、选择研究分数最高的标的，并运行真实的
确定性交易前检查，但不会创建订单。

依次展示：

- 候选全集、冻结数据日、来源和数据指纹；
- 研究结论与 research-only 身份；
- 支持证据、反对证据和失效条件。

> AI 的价值不是把语气变得更肯定，而是把为什么做、为什么不做、什么情况下判断失效同时留下。

### 1:05 - 1:55：展示确定性风控

停在“交易前检查”，展示规则结果、参考价格、数量、预计费用、操作后现金和下跌 10% 的影响。

> 模型意见不能绕过账户、费用、仓位和交易规则。此刻数据库中仍然没有订单。

不要跳过确认框。勾选隔离演示声明，再点击“确认隔离模拟订单”。

### 1:55 - 2:40：成交、费用与盈亏

确认后，系统才写入隔离订单，并按冻结数据中的下一交易日开盘价模拟成交、按收盘价盯市。
展示：

- 已成交状态和成交数量；
- 真实费用与滑点；
- 成交后总资产和样本期盈亏；
- “正式证据污染 = 0”。

> 这笔历史结果只证明产品闭环可以复现，不证明策略有 Alpha，更不证明未来收益。

### 2:40 - 3:00：用诚实边界收尾

展示“当时判断 / 真实模拟结果 / 证据边界”三列和底部研究身份、隔离账本路径、正式实验数量。

> QuantLab 不是让 AI 自动替人炒股，而是把发现、研究、风控、人工确认、成交和复盘变成一条
> 可审计链路；证据不够时，系统宁可拒绝，也不会补造成功。

## 现场故障回退

### 页面显示已经完成

点击演示页左上角“重新开始”。它只删除当前数据指纹对应的隔离 Demo SQLite，不会清空生产库、
用户正常账户或正式成绩。

### 8501 被占用

无需处理。脚本会选择后续空闲端口，以终端打印的 `Local URL` 为准。也可以显式运行
`-Port 8510`。

### 浏览器没有自动打开

复制终端中的 `http://127.0.0.1:<端口>` 到浏览器。服务仍只监听本机回环地址。

### `.venv`、Streamlit 或数据集检查失败

停止演示，不要临时切换生产数据库或在线数据冒充回退。按照 README 的安装步骤重建环境：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev,agents,ui,data,api]"
```

随后先运行 `-CheckOnly`。冻结数据集缺失或指纹校验失败时，应恢复仓库内原始数据集后再演示。

### 网络、外部行情或 LLM 不可用

三分钟主路线不依赖网络、API Key 或实时行情。继续使用首页“完整决策示例”，不要把旧行情、
测试行情或 Historical Demo 表述为 Live 成功。

## 禁止表述

- 不宣称稳定 Alpha、稳定盈利或收益保证；
- 不把 Historical Demo 说成实时行情或正式前瞻证据；
- 不把工程测试通过说成策略有效；
- 不跳过用户显式确认；
- 不在现场启动 `daily-cycle`、`runtime-start`、Scheduler、Worker 或正式样本注册。
